# Frontend session

You are the **frontend** session. Your area is `frontend/` (this folder). Shared rules are in the root `CLAUDE.md`.

## Stack
- React + Vite (JavaScript)
- Tailwind CSS + shadcn/ui. Add components with `npx shadcn@latest add <component>` instead of hand-writing what shadcn already provides.
- React Router for pages

## Talking to the backend
- The API base URL comes from `VITE_API_URL` in `frontend/.env` (local default `http://localhost:5000/api`). Document it in `frontend/.env.example`.
- `../docs/API.md` is the contract. Code against it, not against backend source. If an endpoint you need is missing or unclear, ask the user to get the backend session to add it.
- Keep API calls in `src/lib/api.js`, not inline in components. Load data in components with `useApi` (one request, with retry) or `useProducts` (product lists with load more) from `src/hooks/`; show failures with `LoadError`.

## Commands
Run from `frontend/`. First time: `npm install`, then copy `.env.example` to `.env`.
- `npm run dev`: dev server on http://localhost:5173
- `npm run build`: production build into `dist/`
- `npm run preview`: serve the built `dist/` locally
- `npm run lint`: ESLint
- `npx shadcn@latest add <component>`: add a shadcn/ui component to `src/components/ui/`

## Notes
- This folder already contains this `CLAUDE.md`. When scaffolding (e.g. `npm create vite`), don't let the tool delete it. If it refuses a non-empty folder, scaffold into a temp folder and move the files in.
- `Dockerfile` / `.dockerignore` in this folder, if they exist, belong to the devops session.
- shadcn/ui is set up on Base UI (`base-nova` style), not Radix: compose with the `render` prop (e.g. `<Button render={<Link to="/" />} nativeButton={false}>`), not `asChild`.
- Design system: an editorial luxury look (light, warm black / white / neutrals, serif display type, square corners, hairline rules, slow motion). Tokens and utilities are in `src/index.css` (its header comment is the cheat sheet); `/styleguide` shows them in dev builds. Use `font-serif` + `text-display-*` for display type, `eyebrow` for small caps labels, `page-container` for width and gutters, `py-section` between sections, and put `dark` on a section to flip it to the ink palette. Build pages from the shared pieces rather than a new look: `CtaButton`, `Reveal`, `ImagePlaceholder`, `components/layout/` (header, menu drawer, footer) and `components/brand/`.
- The footer disclaimer is required by the spec. Its text, the working name "Maison Prix" and the page list live in `src/content/site.js`.
- `src/content/brands.js` is placeholder brand copy until the backend serves brands. Never put prices in it: prices only come from the API (official sources). Don't use brand logos or assets; real product images must credit and link their source.
- Files in `src/components/ui/` are generated by the shadcn CLI. Don't hand-edit them; `eslint.config.js` relaxes two rules for that folder.
